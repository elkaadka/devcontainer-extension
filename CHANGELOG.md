# Changelog

## 0.1.0

- First release: webview panel with package catalog, version selection, package sources and mirrors.
- Persistent volumes: a shared one for CLI logins and one for each project's Copilot and VS Code state and shell history.
- Re-generating keeps user settings, comments, features, extensions and mounts.
- `customPackages` setting to add packages or replace built-in ones.
